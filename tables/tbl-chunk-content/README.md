# Measured chunk-content table

`generate.py` reads the measured N2-4 CSV, copies it to `data.csv` and emits `output.md`. The chapter includes this output directly. Each range spans the four tokenizer-specific means; extrema in different columns can refer to different tokenizers. The archived fertility estimate is not used as fallback. Full protocol and input provenance are in `experiments/n2_meaning/chunk-study/README.md`.
